# Duncan's Gassy Adventure

A family-friendly 8-bit-style mobile game from Peter's Arcade. The circus clowns stole the Golden Bagpipes from Castle MacDuncan! Toot-jump, gas-fly and gas-blast silly clowns across the Scottish highlands.

- Story: 5 levels (Glen of Toots, Loch Pfftness, Bagpipe Bridge, Castle Ramparts, The Keep with the Big Top Bertha boss)
- Endless mode with a shared leaderboard
- Toot Board: six quiet synthesized toots

Play: https://ploug76.github.io/duncans-gassy-adventure/
